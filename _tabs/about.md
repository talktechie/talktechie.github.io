## About TalkTechie

TalkTechie is a tech blog run by a software engineer
with 6 years of experience — documenting real engineering
discoveries, not just repeating documentation.

The goal is simple: write the posts I wish existed
when I was figuring things out myself.

## What You Will Find Here

- Deep dives into Spring Boot and Kotlin
- Real production problems and how they were solved
- Honest learning — including the mistakes
- Practical tutorials with real code

## Current Series

**Spring Data JPA with Kotlin** — A senior engineer's
honest exploration of JPA internals, query generation,
memory behaviour and production patterns.
